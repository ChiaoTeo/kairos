# Examples

Example files are organized by role:

- `configs/`: runnable TOML files for backtest and paper runs.
- `strategies/`: importable strategy modules referenced by configs.
- `.kairos/data/`: example `DataStore` datasets.
- `.kairos/runs/`: local run artifacts generated by commands; ignored by git.

## Binance Data Preparation

Download real Binance OHLCV data into the examples data store:

```bash
kairospy data download \
  --root examples/.kairos/data \
  --format jsonl \
  --exchange binance \
  --driver ccxt \
  --symbol BTC/USDT \
  --timeframe 1m \
  --limit 1000 \
  --mode replace
```

Read a few rows back:

```bash
kairospy data read \
  --root examples/.kairos/data \
  --format jsonl \
  --limit 5 \
  market.ohlcv.binance_spot_btc_usdt.1m
```

Then run the Binance backtest:

```bash
kairospy backtest run --config examples/configs/binance_backtest.toml
```

If the download fails with a Binance connection timeout, the code path is present but the current network cannot reach `api.binance.com`.

## Hyperliquid Backtest Example

The Hyperliquid backtest uses a small committed sample dataset under `.kairos/data`:

```bash
kairospy backtest run --config examples/configs/hyperliquid_backtest.toml
```

The generated artifacts are written to:

```text
examples/.kairos/runs/backtest/hyperliquid-sma-backtest/
```

## Hyperliquid Paper Example

The paper example uses a live subscription and requires network access:

```bash
kairospy run daemon start \
  --mode paper \
  --run-id hyperliquid-paper \
  --config examples/configs/hyperliquid_paper.toml \
  --foreground
```
